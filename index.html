Firebase Setup Required To sync bets across devices, paste your Firebase config into index.html:
  1. Go to console.firebase.google.com and create a project
  2. Click Add app (web </>) and copy the firebaseConfig object
  3. Enable Firestore: Build → Firestore Database → Create database (start in test mode)
  4. Paste the config values into the firebaseConfig block near the top of index.html
